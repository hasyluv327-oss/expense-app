# ExpenseFlow — 経費精算システム

スタートアップ向けのポートフォリオ用経費精算Webアプリです。

## 機能

- **経費申請フォーム** — 日付・金額・カテゴリ・支払先・メモ・領収書添付
- **承認フロー** — 申請 → 上長承認 → 経理確認の3ステップ
- **月次集計ダッシュボード** — カテゴリ別内訳（ドーナツグラフ）・月次推移（棒グラフ）・統計サマリー
- **申請履歴** — ステータス・カテゴリでフィルタリング

## 技術スタック

- Vanilla JS (ES2022)
- Chart.js 4.4（CDN）
- CSS Custom Properties + Grid/Flexbox
- localStorage によるデータ永続化

## 起動方法

ビルド不要です。`index.html` をブラウザで開くだけで動作します。

```bash
# ローカルサーバーで起動する場合
npx serve .
# または Python で
python3 -m http.server 8080
```

## デプロイ

GitHub Pages / Netlify / Vercel にそのままデプロイ可能です。

## スクリーンショット

| ダッシュボード | 経費申請 | 承認管理 |
|---|---|---|
| 月次グラフ・統計 | 申請フォーム | 上長・経理の承認操作 |
